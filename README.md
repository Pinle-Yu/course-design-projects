# 课程设计项目

本仓库收录两项小组课程设计。两个项目中本人均担任组长，负责任务分配、关键模块实现与整机联调。

| 项目 | 简介 |
|---|---|
| [数电课设：四路病房呼叫系统](数电课设-病房呼叫系统/README.md) | 基于 74 系列逻辑芯片和 NE555，实现四路呼叫、优先级判断、编号显示和声光报警。 |
| [单片机课设：低功耗桌面温湿度检测仪](单片机课设-温湿度检测仪/README.md) | 基于 STM32G030K6T6 和 SHT40，实现按键唤醒、温湿度采集、动态显示和自动休眠。 |

## 个人工作（STAR）

### 数电课设：四路病房呼叫系统

- **情境（Situation）**：课程要求完成一个能够区分多路病床呼叫、显示呼叫编号并进行声光提示的数字电路系统。小组需要把逻辑芯片方案从原理验证推进到可焊接、可调试的双层 PCB 实物。
- **任务（Task）**：作为组长，我负责安排模块分工，并承担译码显示链路、原理图、PCB 布局布线以及仿真和整机联调等关键工作。
- **行动（Action）**：在 Multisim 中搭建并验证 74LS148N 优先编码、74LS04N 反相、74LS48N 数码管译码和 NE555 蜂鸣报警链路；在嘉立创 EDA 中完成原理图整理、封装检查、双层 PCB 走线和电源连接；组织组员完成焊接、通电检查和多路同时呼叫测试，并根据测试现象排查连接和显示问题。
- **结果（Result）**：形成可复现的 Multisim 仿真工程、嘉立创 EDA 工程和完整 PCB 设计资料，实现四路呼叫输入、最高优先级编号显示及蜂鸣器报警，最终完成实物演示和项目归档。

### 单片机课设：低功耗桌面温湿度检测仪

- **情境（Situation）**：课程要求制作一台能够采集温湿度、显示测量结果并在空闲时降低功耗的桌面仪器。小组基于嘉立创公开课程方案完成板级制作、软件整合和实物联调。
- **任务（Task）**：作为组长，我负责任务分配，并承担原理图与 PCB 设计、CubeMX 工程配置、关键软件流程整合以及烧录后的整机调试。
- **行动（Action）**：围绕 STM32G030K6T6 主控，完成 SHT40 的 I2C 采集、SN74HC595 驱动数码管动态扫描、PB5 按键外部中断唤醒和 Sleep 休眠流程的整合；根据硬件连接核对引脚和显示时序，组织组员完成贴片焊接、程序烧录、按键唤醒、温湿度显示与自动休眠测试，并整理完整 Keil 工程和软件总体流程图。
- **结果（Result）**：实现按键唤醒后采集并显示温度、湿度，显示结束后关闭数码管并重新进入休眠；完成原理图、PCB 走线、流程图和完整工程归档，形成可供复核和复刻的项目材料。
