# 课程设计项目

本仓库收录两项小组课程设计，点击下方链接可以查看详细项目内容。

## 项目与个人工作

### [数电课设：四路病房呼叫系统](数电课设-病房呼叫系统/README.md)

- **项目内容：** 使用 74 系列逻辑芯片和 NE555，实现四路病床呼叫、优先级判断、编号显示和声光报警。
- **我负责的内容：**
  - **译码显示仿真：** 使用 Multisim 验证译码显示模块，核对逻辑连接和数码管显示结果。
  - **PCB 设计与焊接：** 在嘉立创 EDA 中完成原理图整理、器件封装核对、电源连接和双层 PCB 布局布线，并完成板卡焊接和上电检查。

### [单片机课设：温湿度检测仪](单片机课设-温湿度检测仪/README.md)

- **项目内容：** 基于 STM32G0 低功耗系列芯片和 SHT40 温湿度传感器，实现按键唤醒、温湿度采集、数码管动态显示和自动休眠。
- **我负责的内容：**
  - **PCB 设计与焊接：** 完成原理图与 PCB 设计，核对主控、传感器、数码管驱动和按键接口的引脚连接，检查板层走线和器件布局，并完成贴片焊接。
  - **休眠代码：** 编写空闲状态下暂停系统滴答定时器、进入低功耗睡眠模式，以及外部中断唤醒后恢复系统节拍的代码流程。
