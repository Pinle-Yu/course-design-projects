# 课程设计项目

本仓库收录两项小组课程设计。两个项目中本人均担任组长，主要负责 PCB 设计；此外完成数电项目的译码显示仿真验证，以及单片机项目的休眠代码编写，并参与整机联调。

## 项目与个人工作

### [课设4路病房呼叫系统](数电课设-病房呼叫系统/README.md)

- **项目内容：** 使用 74 系列逻辑芯片和 NE555，实现四路病床呼叫、优先级判断、编号显示和声光报警。
- **主要负责 PCB：** 在嘉立创 EDA 中完成原理图整理、器件封装核对、电源连接和双层 PCB 布局布线，重点检查走线连通性、器件位置与接口方向。
- **仿真验证：** 使用 Multisim 对译码显示模块进行仿真，核对逻辑芯片之间的信号连接和数码管显示结果。
- **协作与产出：** 作为组长负责分工协调，并参与焊接、上电检查和整机测试，最终整理出 PCB 走线图、仿真工程、EDA 工程和实物演示。

### [单片机课设：温湿度检测仪](单片机课设-温湿度检测仪/README.md)

- **项目内容：** 基于 STM32G030K6T6 和 SHT40，实现按键唤醒、温湿度采集、数码管动态显示和自动休眠。
- **主要负责 PCB：** 完成原理图与 PCB 设计，核对主控、传感器、数码管驱动和按键接口的引脚连接，检查板层走线、器件布局及可焊接性。
- **主要负责休眠代码：** 编写并整合空闲状态下暂停 SysTick、进入 Sleep，以及 PB5 外部中断唤醒后恢复系统节拍的代码流程。
- **协作与产出：** 作为组长负责任务分配，配合组员完成传感器采集、显示驱动、贴片焊接、程序烧录和整机联调，整理出完整 Keil 工程和软件总体流程图。
