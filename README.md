# 课程设计项目

本仓库收录两项小组课程设计。两个项目中本人均担任组长，负责任务分配、关键模块实现与整机联调。

| 项目 | 简介 |
|---|---|
| [数电课设：四路病房呼叫系统](数电课设-病房呼叫系统/README.md) | 基于 74 系列逻辑芯片和 NE555，实现四路呼叫、优先级判断、编号显示和声光报警。 |
| [单片机课设：低功耗桌面温湿度检测仪](单片机课设-温湿度检测仪/README.md) | 基于 STM32G030K6T6 和 SHT40，实现按键唤醒、温湿度采集、动态显示和自动休眠。 |

## 我的工作

### 数电课设：四路病房呼叫系统

作为组长，我负责模块分工，并承担译码显示链路、原理图、PCB 布局布线、仿真验证和整机联调。围绕四路病床呼叫需求，我在 Multisim 中验证 74LS148N 优先编码、74LS04N 反相、74LS48N 数码管译码和 NE555 蜂鸣报警链路；在嘉立创 EDA 中完成封装检查、电源连接和双层 PCB 走线；组织组员完成焊接、通电检查及多路同时呼叫测试。最终实现呼叫输入、最高优先级编号显示和声光报警，整理出可复现的仿真工程、EDA 工程、PCB 资料和实物演示。

### 单片机课设：低功耗桌面温湿度检测仪

作为组长，我负责任务分配，并承担原理图与 PCB 设计、CubeMX 工程配置、软件流程整合和烧录后的整机调试。基于嘉立创公开课程方案，我围绕 STM32G030K6T6 整合 SHT40 的 I2C 温湿度采集、SN74HC595 数码管动态扫描、PB5 外部中断唤醒和 Sleep 休眠流程；根据硬件连接核对引脚与显示时序，组织组员完成贴片焊接、程序烧录、唤醒显示和自动休眠测试，并整理 Keil 工程及软件总体流程图。最终实现按键唤醒后采集并显示温湿度、显示结束后关闭数码管并重新休眠，形成可复核和复刻的硬件、软件及工程资料。
